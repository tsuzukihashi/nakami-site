使い方とお問い合わせ

1. ファイルを開く

［ファイルを開く］で選ぶか、ファイル App や共有から「なかみ」を選びます。ファイル App の中では、長押しの「クイックルック」でアプリを開かずに見られます。

2. JSON

木の行を押すと畳んだり開いたりします。値を長押しすると、その場所（$.items[1].name の形）や値をコピーできます。壊れているときは、最初におかしい文字の行と列が出ます。

3. CSV・TSV

列の見出しを押すと並べ替え、長押しで絞り込みます。セルを押すと全文が見られます。1行目を見出しにするかは設定で選べます。

4. Markdown

右上で下見と元の字を切りかえます。見出しの一覧から飛べます。画像は同じフォルダにあるものだけ描きます。

よくあるご質問

文字化けします

開いたファイルの右上の文字コードを押して、Shift_JIS や UTF-16 を選び直してください。

ファイルを直せますか

1.0 は読むための道具です。JSON の整え・縮め、CSV から JSON への変換は「別のファイルとして保存」で作れます。

Help & Contact

1. Open a file

Tap Open File, or choose Nakami from the Files app or the share sheet. In the Files app, touch and hold a file and choose Quick Look to see it without opening the app.

2. JSON

Tap a row in the tree to fold or unfold it. Touch and hold a value to copy its path (as $.items[1].name) or the value. For broken files, the line and column of the first error are shown.

3. CSV and TSV

Tap a column header to sort, and touch and hold to filter. Tap a cell to see it in full. Choose in Settings whether the first row is the header.

4. Markdown

Switch between preview and raw text at the top right. Jump from the outline. Images are drawn only from the same folder.

FAQ

Text is garbled

Tap the encoding at the top right of the open file and pick Shift_JIS or UTF-16.

Can I edit files?

Version 1.0 is a viewer. Pretty-printed or minified JSON, and JSON converted from CSV, can be made with Save as New File.
